Draws an anti-aliasing-free straight line into a MiniFB pixel buffer with bounds checking.

Parameters
aStart point of the line (screen-space pixels).
bEnd point of the line (screen-space pixels).
buffFlat pixel buffer of size width * height, modified in place.
colorRGB colour to paint the line with.
widthTotal pixel width of MiniFB window
heightTotal pixel height of MiniFB window
Note
a and b are taken by value; the algorithm may swap their coordinates internally without affecting the caller's variables.
Example
std::vector<std::size_t> buffer(WIDTH * HEIGHT, 0);
rgb_color red(255, 0, 0);
line({0, 0}, {WIDTH - 1, HEIGHT - 1}, buffer, red, WIDTH, HEIGHT);
