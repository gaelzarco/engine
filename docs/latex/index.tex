A C++23 3D renderer built with Mini\+FB as single dependency. Targets Unix environments.\hypertarget{index_features}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_features}

\begin{DoxyItemize}
\item Window rendering with \href{https://github.com/nicowillis/minifb}{\texttt{Mini\+FB}}
\item OBJ file parser built from scratch via named module ({\ttfamily import \doxylink{classobj}{obj}})
\item 3D rendering pipeline built from scratch via named module ({\ttfamily import render})
\end{DoxyItemize}\hypertarget{index_requirements}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{index_requirements}
